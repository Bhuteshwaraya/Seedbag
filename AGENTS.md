# Working on Seedbag

This repository distributes a project continuity program. Read README.md and OPERATIONS.md for purpose and behavior. The repository itself is the seed source, not a planted user's continuity ledger.

Keep examples arbitrary. A project label, the person directing the AI, and the intended beneficiary are distinct. Do not infer personal identities or roles from accounts, folders, machines, or the framework's author. Use synthetic test data, and keep private project case studies and conversation history out of this repository.

Plant only into new empty folders. Existing projects keep their independent runtime and are not migration targets. Preserve explicit provenance/dispositions, append-only records, stale-write checks, exact verification bindings, and truthful local/shared status. Respect the limits in OPERATIONS.md: no automatic chat capture, semantic proof, distributed ledger merge, or exactly-once external guarantee.

Use an available Python 3.11+ interpreter. Run relevant tests under tests/ for changes, and the complete suite before a release. Refresh validation evidence and MANIFEST.json only from the actually tested files. The repository workflow runs the tests; it is not automatically installed into planted projects.

Keep the MIT license notice with distributed runtime copies. New projects use SEEDBAG_LICENSE.txt for this notice so their own content can have a separately chosen license. User requests and existing authorization govern work; do not add repeated approval rituals.
