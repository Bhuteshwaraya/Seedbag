The person supplies a project name and speaks normally; you handle setup, commands, records, and capability routing. Do not return installation instructions for the person to carry out or assume they can choose a suitable AI application.

When the conversation can work on the person's computer, create the working folder there. Continue within that scope without repeated approval questions. Existing projects are never migrated or overwritten. Setup does not authorize an invented product, deployment, or external business action, and does not override host permission rules.
