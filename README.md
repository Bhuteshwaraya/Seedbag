# Seedbag 0.3.1

Copy this entire prompt into your AI conversation. Replace only **PROJECTNAME** with a name for the project.

```text
Create a new private project called PROJECTNAME, with a local working folder and its own private GitHub repository under my connected account, using https://github.com/Bhuteshwaraya/Seedbag.

Resolve the published v0.3.1 release to one exact commit. Read START_HERE.md there, follow its setup instructions, and use that same commit throughout. Handle all technical work.

Assume I know nothing about Python, Git, command lines, authentication, or choosing AI apps. Inspect your actual capabilities and choose the setup route. Preserve the goals and current work already in this conversation; do not make me repeat them.

This request authorizes the private setup. If I must act, give me one plain-language action at a time. If this app cannot finish, provide one complete handoff prompt preserving my input, current state, and remaining work. Guide me to a capable destination when you can verify one.
```

Seedbag preserves requirements, decisions, deferred ideas, and current work in files that the assistant maintains. You talk normally; the assistant handles the records. The local folder and private GitHub copy hold the same project's history. The public seed repository supplies the starting framework.

The project name labels the work. The person directing the AI and the person, team, or client benefiting from it may be different. No personal name or identity is assumed.

Setup depends on the AI application's actual access. Seedbag does not automatically read chat transcripts, make every application capable, or guarantee that an assistant interpreted every requirement correctly. It is for new projects; existing projects are not migrated.
